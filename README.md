# 一箭又一箭（Arrow Puzzle）

一个使用 **Python + Pygame** 开发的"一箭又一箭"风格箭头解谜小游戏，为软件工程课程作业项目，借助 AIGC 工具（Claude Code）辅助开发。

## 游戏简介

棋盘上分布着上、下、左、右四种方向的箭头。玩家需要观察箭头之间相互阻挡的关系：

- **点击箭头**：若箭头前进方向（同一行/同一列）上、到棋盘边界之间没有其他箭头阻挡，该箭头会**飞出棋盘**并被消除；
- **被阻挡时**：箭头无法飞出，会原地晃动并闪烁红色提示，同时**消耗一次失误机会**；
- **通关条件**：清除棋盘上全部箭头，按失误次数获得 1~3 星评价；
- **失败条件**：失误机会（每关 3 次）耗尽。

游戏共 8 个关卡（第 6~8 关由随机生成器 + 固定种子生成），全部经过求解器验证保证可通关，难度循序渐进；另有**无尽模式**可挑战随机生成的关卡。

## 主要功能

| 类别 | 功能 |
| ---- | ---- |
| 基础玩法 | 四方向路径检测、飞出/碰撞动画、失误机制、通关/失败流程、重新开始 |
| 关卡系统 | 8 个关卡 + 关卡选择界面（星级、解锁进度）+ 无尽模式 |
| 辅助功能 | 提示（高亮安全箭头）、撤销上一步、AI 演示（自动求解通关） |
| 计分系统 | 实时计时与得分，通关界面显示得分/用时/星级，记录历史最佳 |
| 进度存档 | save.json 自动保存解锁进度、最佳成绩与进行到一半的对局（继续游戏） |
| 随机关卡 | 逆序放置算法生成**保证可通关**的随机关卡 |
| 视听效果 | 飞出拖尾+旋转、粒子爆发、碰撞晃动+摇摆+红闪、程序合成音效 |

## 安装和运行方法

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行游戏（项目根目录）
python main.py
```

### 打包为可执行文件（可选）

```bash
pip install pyinstaller
tools\build_exe.bat          # 输出 dist\ArrowArrow.exe，双击即可运行
```

打包后的 exe 不依赖 Python 环境；游戏存档 save.json 保存在 exe 所在目录。

## 游戏操作说明

| 操作 | 说明 |
| ---- | ---- |
| 鼠标点击箭头 | 前方无阻挡：箭头飞出棋盘；前方有阻挡：晃动 + 摇摆 + 红闪，失误次数 -1 |
| `提示` 按钮 | 高亮一支当前可以安全消除的箭头（金色呼吸圈） |
| `撤销` 按钮 | 撤销上一步操作（恢复箭头和失误次数） |
| `演示` 按钮 | AI 自动求解当前关卡，自动演示通关步骤（再次点击停止） |
| `重新开始` 按钮 | 当前关卡恢复到初始状态 |
| `主菜单` 按钮 | 返回开始界面 |

游戏界面顶部显示当前关卡、剩余箭头、剩余失误、用时和实时得分；碰撞时还会圈出阻挡你的那支箭头。通关界面显示得分、用时与星级，并自动记录历史最佳成绩。

## 项目结构

```
├── main.py                  # 游戏入口
├── game/
│   ├── config.py            # 窗口/棋盘/颜色/动画参数
```

## 运行测试

```bash
python -m unittest discover -s tests -v
```

34 个测试用例全部通过，覆盖：四方向路径检测、边界处理、碰撞与失误机制、通关/失败判定、重新开始、全部关卡的**可解性验证**、撤销、随机生成关卡的可解性、得分计算与存档读写。

## 随机关卡生成算法

无尽模式使用"**逆序放置**"算法生成关卡：按消除顺序的逆序逐支放置箭头，放置每支箭头时保证其正前方路径上没有已放置的箭头——由于已放置的箭头都会在它之后才被消除，这样生成的关卡必然存在通关顺序（放置顺序的逆序即为一组解）。该性质由单元测试对多组随机种子进行了验证。
